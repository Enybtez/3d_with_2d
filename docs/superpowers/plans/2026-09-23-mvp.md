# Illustration to Toon MVP Implementation Plan

> **For agentic workers:** 本计划由当前会话直接执行；每项以测试先失败、再实现、再验证的顺序推进。

**Goal:** 一张插画经本地多 Agent、Skill 和 MCP 流程生成 GLB、三渲二 PNG 与质检记录。

**Architecture:** FastAPI/CLI 进入编排层；两名视觉 Agent 调用本地 Ollama；建模和风格 Agent 通过 MCP stdio 服务调用本地 Hunyuan API 与 Blender。任务以 JSON 文件持久化。

**Tech Stack:** Python 3.11、FastAPI、MCP Python SDK、Pillow、Ollama、Hunyuan3D 2.1、Blender 4.x。

**Spec:** `docs/superpowers/specs/2026-09-23-illustration-to-toon-design.md`。

## Global Constraints

- 单物体 PNG/JPEG，不超过 10 MB。
- 正式运行只连本机模型服务，任务串行。
- MCP 文件操作仅限 `data/jobs`，错误必须写入任务状态。
- 实机 GPU/Blender 效果未经验证时标记为未完成。

## Review Focus

- 损坏图片与超大图片应在排队前拒绝。
- 伪造的路径穿越应被 MCP 工具拒绝。
- 模型返回非 GLB 字节应标失败。
- 服务重启后旧任务状态仍可读取，未完成任务可识别为中断。
- LLM 返回无效 JSON 时应标失败而不是生成空描述。
