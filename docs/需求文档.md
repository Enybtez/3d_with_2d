# MVP 需求文档

版本：0.1，2026-09-23。目标用户：参赛团队现场操作员。用途：从一张自有单物体插画生成可下载的 3D GLB 和三渲二预览图，展示本地多 Agent、Skill 与 MCP 的协作。

## 范围

### 功能需求

| ID | 需求 | 第一阶段验收 |
|---|---|---|
| R1 | 接收一张 PNG/JPEG，限制 10 MB，拒绝无效图像 | API 测试覆盖合法与非法输入 |
| R2 | 每次提交创建唯一任务，保存原图、状态、元数据和错误 | 重启进程后可查询已有任务记录 |
| R3 | 分析 Agent 加载版本化 Skill，调用本地视觉模型产生主体描述 | 测试验证实际读取 Skill，且请求仅发往配置的本地 Ollama 地址 |
| R4 | 建模 Agent 经 MCP 工具调用本地 2D→3D 服务，保存 GLB | MCP 端到端测试验证工具调用与 GLB 文件 |
| R5 | 风格 Agent 经 MCP 工具调用 Blender，输出 3D 渲染的卡通预览 PNG | 渲染命令测试，Spark 实机测试补验像素效果 |
| R6 | 质检 Agent 比较原图和预览并返回简短意见 | 测试验证结果写入任务记录 |
| R7 | 页面轮询任务状态并展示预览和下载链接 | API 和手工页面检查 |
| R8 | 提供 CLI 运行方式，便于赛事现场排障 | 命令帮助和一次替身服务链路检查 |
| R9 | MCP 服务可被外部兼容客户端发现、调用 | list_tools 与 call_tool 测试 |

### 非功能需求

- 正式推理与渲染均在 DGX Spark 本机执行；首次下载权重可联网，运行时不调用云端模型。
- 输出使用任务目录隔离。MCP 工具只读写配置的数据根目录。
- 单机单任务串行；任务失败要保留阶段和错误，禁止静默伪造结果。
- 软件层要求 Python 3.11、Ollama、Blender 4.0 或 4.2；Hunyuan3D 置于独立环境。版本以 Spark 实机兼容性校验为准。
- 日志与任务状态可读，不能记录原始图像的 base64 或私有模型密钥。

## 不包含

- 人物、多物体场景、动画、自动骨骼、多视角重建、商用级拓扑优化。
- 自动多轮重试和自动修改模型；用户可重新提交。
- 云端部署和公开互联网访问；现场局域网访问需自行加访问控制。

## 演示成功标准

在 Spark 上用 3 张不同的单物体插画，每张均得到非空 GLB 与非空三渲二 PNG，页面显示四个 Agent 的步骤和质检文字。记录每次耗时、峰值内存、失败案例；具体时延门槛在实机基线测完后确定，不预设虚假的性能承诺。
